# ADR-0014: 합성 대화 상태를 현재 입원에 연결

- 상태: 제안됨
- 작성일: 2026-09-16
- 적용 범위: 고정 합성 환자 975의 내부 대화 시험
- 관련 문서: [PRD 대화 상태](../../docs/delirium-familiar-voice/02-patient-conversation.md), [Supabase 선택](0004-supabase-auth-postgres.md), [Gate07](../../docs/delirium-familiar-voice/07-pre-patient-trial-safety-ethics-gate.md)

## 배경

기존 연결 기기 API는 요청마다 새 `ConversationSession`을 만들었다. 첫 `DIRECTED` 발화 뒤 `UNCERTAIN` 후속 발화를 보내면 서버가 다시 `IDLE`로 판단해 응답을 버린다. Vercel 함수 메모리는 인스턴스 사이에 공유되지 않으므로 앱 프로세스 안의 세션으로도 이 문제를 해결할 수 없다.

## 결정 초안

고정 합성 환자의 **현재 입원**에 하나의 PostgreSQL 대화 상태를 둔다. 현재 배정된 익명 iPad 계정만 상태를 읽고, 읽은 세션 ID·버전으로 비교 후 갱신한다. 읽기와 갱신 때마다 현재 입원·기관 시험 승인·환자 동의/assent·기기 결속을 검사한다. 상태에는 `IDLE`/`ACTIVE_LISTENING`, 활동 시각, 환자 거부, 마지막 시험 턴 ID만 저장하고 글·오디오·모델 입력·답변을 저장하지 않는다. `AMBIENT`는 상태와 공급자에 전달하지 않는다. 서로 다른 기기의 경합이나 오래된 버전은 답변 전에 차단한다.

환자 거부가 확정되면 같은 DB 트랜잭션에서 입원 세션을 멈추고 기존 `patient_dissent` 감사 이벤트도 기록한다. 정상 발화가 먼저 버전을 갱신하거나 다른 기기가 대화 행을 소유해도, **현재 권한 있는 기기의 명시적 거부는 최신 입원 행에 단조롭게 고정**한다. 이 이벤트를 보는 보호자 음성 선택·예약 병원 메시지 경로까지 닫으며, 새 익명 기기를 연결하거나 기존 기기 계정을 삭제해도 같은 입원의 거부 상태는 풀리지 않는다. 재개 절차는 기관 승인 전까지 제공하지 않는다. 서버는 외부 임베딩 전과 답변/TTS 직전에 세션 ID·버전과 권한을 다시 읽는다. 이미 시작된 공급자 호출을 소급 취소하는 보장은 없다.

45초 무음 만료는 현재 **DB 갱신 시각**부터 계산한다. 실제 환자가 응답 음성을 다 들은 뒤의 무음 시간을 측정한 것이 아니며, iPad의 재생 상태를 서버가 증명하지 못한다. 서버는 다회차 **활성화 상태**만 잇고 LLM의 이전 턴 문맥은 유지하지 않는다. 마지막 턴 ID는 바로 이전 재시도와 버전 경합만 막으며 A→B 뒤 예전 A를 다시 보내는 재사용까지 멱등으로 처리하지 않는다. 이러한 경계와 병실 화자 판정·첫 실제 청취 지연은 환자 대상 시험 전에 따로 검증해야 한다.

## 검증과 안전 영향

작업 전용 로컬 DB에서 migration 24개를 빈 상태로 재적용했고 pgTAP 558개/19파일이 통과했다. 정상 턴이 먼저 커밋한 뒤 **오래된 버전의 거부가 감사 이벤트까지 고정되는 경합**, 다른 활성 기기의 거부, 권한 없는 기기의 거부 차단을 DB에서 검증했다. 실제 로컬 Auth/Data API와 FastAPI의 **합성 메타데이터·모의 TTS** 왕복에서는 첫 `DIRECTED` 뒤 별도 클라이언트의 `UNCERTAIN` 응답, 중복/버전 경합·동의 철회 차단, 후속 발화의 직접 전사 비저장을 확인했다. 시험 뒤 환자·세션·전사·시험 음성 메타데이터는 0행이다. Supabase advisor의 새 오류는 없고 기존 병원 메시지 다중 SELECT 정책의 성능 경고 한 건은 남는다.

이 변경은 주변 발화의 불필요한 전송과 기기 교체를 통한 거부 우회를 줄이지만 **등록 환자 화자 확인**이나 실제 임상 동의·기관 승인·공급자 보존 정책을 증명하지 않는다. 상태 만료 시점, 재개 권한, 반복 턴 ID, 실제 의료진 알림 경로와 환자에게 들리는 음성은 임상·기관 검토가 필요하다. [Gate07 네 조건](../../docs/delirium-familiar-voice/07-pre-patient-trial-safety-ethics-gate.md#23-pre-patient-trial-gate)이 끝나기 전 실제 환자 자료나 병실 시험을 열지 않는다.
