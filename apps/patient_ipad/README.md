# iPad 마이크 내부 시험

Flutter/`record`의 16 kHz mono PCM 스트림으로 기기 내 발화 **후보**를 감지합니다. 1초 이내의 휘발성 직전 버퍼와 최대 8초 후보만 메모리에 두고, 기본적으로 오디오는 폐기합니다. 시험자 본인 음성 확인을 선택한 경우에만 후보 한 건을 최대 30초 동안 메모리에 남기며, 직접 누르면 WAV로 변환해 HTTPS `POST /internal/synthetic/audio`에 전송합니다. 주소·내부 토큰은 화면에서 입력하고 토큰은 배경 전환 시 지웁니다. 응답 MP3는 iOS `AVAudioPlayer(data:)`로 메모리에서 재생하며, 재생 중단을 확인하지 못하면 마이크 재시작 전에 다시 중단을 시도합니다. 원본·응답 오디오는 앱 파일이나 DB에 저장하지 않습니다. 서버와 음성 공급자에는 시험 오디오가 전달될 수 있으므로 실제 환자 자료를 입력하지 마세요.

이 연결은 **자가 음성 내부 시험**입니다. 환자 목소리 등록·화자 판정, 자동 후보 전송, 실제 보호자 음성 등록과 운영 대화는 아직 없습니다. 발화 끝의 기본 무음 창은 PRD 범위 안인 0.9초이며 `SpeechCandidateDetector.silenceMilliseconds`로 iPad 시험에서 조절할 수 있습니다. 에너지 임계값과 무음 창은 실제 병실 평가 전에 환자 판정에 사용할 수 없습니다.

`flutter test`, `flutter analyze`, iOS 시뮬레이터 빌드로 코드 경로를 확인할 수 있습니다. 실제 iPad 마이크·권한·중단·재생 동작과 클라우드 왕복은 기기/공급자 설정 후 따로 검증해야 합니다. 이 화면은 내부/자가 음성 시험 전용이며 [안전 게이트](../../docs/delirium-familiar-voice/07-pre-patient-trial-safety-ethics-gate.md) 통과 전 실제 환자에게 사용하지 않습니다.
