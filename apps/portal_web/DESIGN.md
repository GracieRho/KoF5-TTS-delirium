# Familiar Voice 포털 디자인

- 방향: 병동 워크스테이션. 장식보다 현재 상태, 담당 범위, 다음 행동을 먼저 보인다.
- 색: 병동 청록 `#123f3b`, 작업면 `#f5f7f5`, 종이 `#ffffff`, 본문 `#1b2927`, 경고 `#9a4d20`, 위험 `#9b3039`.
- 글꼴: 제목은 `Nanum Myeongjo`, 본문은 `Pretendard` 계열을 우선하고 설치되지 않으면 한국어 시스템 글꼴로 대체한다.
- 배치: 보호자는 한 단계씩 읽는 좁은 흐름, 병원은 환자 목록과 상세 작업을 나란히 둔 마스터-디테일이다.
- 구성: 4px/8px 간격, 8px 이하 라운드, 상태는 색뿐 아니라 문구로 표현한다. 모바일에서는 모든 열을 한 열로 접는다.
- 금지: 환자 정보 장식화, 중첩 카드, 그라디언트, 자동 재생 애니메이션, 키 또는 토큰 노출.
