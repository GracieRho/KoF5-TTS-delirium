## 자료 계약과 권한

- 소개·기억 원본 ID와 제출 내용은 사본에 보존한다. 자료 ID·revision·content_hash로 확인한다. 음성 공급자 ID·키는 보내지 않는다.
- 유효한 보호자 연결·현재 입원만 제출 가능하다. 담당 돌봄 작성 권한이 있고 제출자가 아닌 직원만 검토한다. 일반 클라이언트의 직접 INSERT/UPDATE/DELETE는 허용하지 않는다.
- 검토 완료 자료만 같은 환자·입원의 취소되지 않은 계획에 연결할 수 있다. 자료 검토는 공급자 등록 검증·음성 재생 승인이 아니다.
- 음성 상태는 보호자가 직접 RPC로도 제출할 수 있는 값이다. 모든 상태에 **보호자 제출·등록 여부 미검증**을 본문 표시하며, 공급자 등록 근거로 사용하지 않는다.
- SQLite 원본 수정은 이미 보낸 불변 사본을 자동 변경하지 않는다. 변경 후 새 자료 보내기 또는 공유 철회가 필요하다. 공유 당시 내용은 제출 목록에서 확인한다.
- 실제 환자 기기 및 기존 합성 전용 승인/재생 경계는 확장하지 않았다. 임상 진단·처방·자동 재생 동작은 바꾸지 않았다. 실제 환자 적용 전 기관·임상 검토가 필요하다.
