# 설명 문구와 선택 메뉴 정리

2026-10-16. 기존 작업 worktree의 보호자·병원 화면에 적용했다.

- 화면 목적을 반복하는 제목 아래 문단, 사이드바 부제·하단 홍보 문구, 읽기 전용 조회 성공 토스트를 제거했다.
- 작업에 필요한 설명은 공용 `HelpTooltip`으로 옮겼다. 제목·선택 필드·편집 시트에 배치하고 hover/focus, 클릭 고정, Escape·바깥 클릭 닫기를 지원한다.
- 권한 없음·오류·미연결·실제 처리 상태·입력 동의와 환자 데이터는 유지했다. 열람 범위 설명은 도움말에 두되 미확인 환자가 있으면 짧은 상태를 표시한다. 임상 정책이나 접근 권한은 변경하지 않았다.
- 모든 직접 `<select>` 호출을 공용 `Select`로 교체했다. 병원/보호자 테마를 상속하며 팝오버는 시트보다 위에 열린다. 방향키·Home/End·Enter/Space·Escape·Tab·글자 탐색, 비활성 항목 건너뛰기, 실제 폼 값·required 검사를 유지한다.
- 공용 컴포넌트의 회귀 검사와 실제 병원 필터, 도움말 클릭, 키보드 선택, 편집 시트의 필수 결과 누락 차단, Escape 시 메뉴만 닫기, 보호자 기억 분류를 확인했다. 검증 중 환자 기록을 새로 저장하지 않았다.
- 모바일 390×844에서 메뉴가 화면 안에 표시되고 문서 폭은 390px였다. 임시 viewport는 복원했다.
- 프론트 테스트 53개·TypeScript/Vite 빌드, architecture check·생성기 7개 검사, diff 검사를 통과했다. jsdom은 top layer 렌더링을 구현하지 않아 테스트 환경에 popover API 모형을 두고 실제 표시·잘림은 브라우저에서 확인했다.

스크린샷: `hospital-select.png`, `hospital-help.png`, `mobile-select.png`, `family-select.png`.
