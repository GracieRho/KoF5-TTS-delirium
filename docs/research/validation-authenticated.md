# 실제 보호자 인증·자유문장 해석 후속 검증

2026-10-27. 8767 서버의 실제 Supabase Auth 인증, 기존 보호자 저장 자료 조회, 직접 입력 해석을 이어서 검사했다. 인증·저장 함수를 대체하지 않았다. 기존 PR9의 합성 인증 fixture 검사와 구분한다.

## 발견한 문제와 수정

1. 저장된 기억 6개가 있어도 말투가 비어 있으면 “먼저 가족의 기억을 준비해주세요”라고 표시했다. 이제 누락 항목만 안내한다. 말투만 없으면 저장된 호칭과 대화에 쓸 기억 수를 표시하고 같은 화면에서 말투를 선택·저장한 뒤 인터뷰를 연다. 피해야 할 기억은 대화용 개수에서 제외하므로 이 계정은 전체 6개 중 5개다. 저장 실패는 화면에 표시하고 아직 준비됐다고 전환하지 않는다. 다른 보완 링크와 새로고침 버튼은 간격을 둔 액션 행을 쓴다.
2. 웹의 `/interpret` 호출에 보호자 API가 요구하는 `X-Kof5-Studio: 1`이 누락되어 실제 인증에서는 거부됐다. 공통 호출 함수에 추가하고 Authorization과 함께 보내는 회귀 검사를 보강했다. 기존 인증·Origin 검증은 유지했다.

## 실제 실행 경로

- Docker가 꺼져 있었고 기존 프로젝트 전용 Supabase 4개 컨테이너가 시작된 뒤 Auth 연결을 확인했다. 기존 볼륨·스키마·계정을 재생성하거나 seed를 덮어쓰지 않았다. API/DB는 127.0.0.1의 54341/54339 포트를 유지했다. 공유 서비스는 변경하지 않았다.
- 문서에 등록된 보호자 계정의 실제 로그인과 `portal_access`를 통과해 기존 기억 6개와 호칭을 조회했다. 해당 계정/자료는 개발용 가상 정보이며 실존 보호자나 환자 자료가 아니다.
- 실제 저장 화면에 새 말투 필드가 없어 인터뷰가 막혔다. 새 인라인 폼에서 임시 존댓말 선택→PUT 저장→재조회→질문 시작을 확인했다.
- 브라우저에서 가상 문장 “그럼 지금 어떤 게 좋아?”를 동의 후 전송했다. 실제 `/research-api/interpret` → 보호자 권한 확인 → 기존 SQLite 자료 조건 확인 → OpenRouter Nemotron 3 Ultra 무료 모델 → b 분류 → 진행 1/8 반영을 확인했다.
- 이후 선택 7개를 더 입력해 8/8 완료, 직접 입력 원문 보존과 반영 수 8개, 별도 heldout 표현 표시를 확인했다. 이 선택은 흐름 검사이며 실제 보호자 선호 관측이 아니다.
- 검수용 존댓말 설정은 원래 미설정 상태로 복원했다. 응답 재조회로 나머지 가족 소개와 기억 6개가 동일함을 확인했다. 사용자가 직접 말투를 고를 수 있는 수정 화면을 남겼다.
- 390px에서 문서 폭도 390px이며 임시 viewport를 복원했다. 기존 인증/DB 서비스와 8767 서버는 사용을 위해 유지했다.

**실제 로컬 Supabase Auth + 기존 SQLite 보호자 저장소 + 무료 공급자 연결의 통합 검사다. 원격 Supabase workspace RPC와 실존 보호자의 계정/자료를 검증한 결과가 아니다.**

## 가상 문장 분류 평가

`configs/research/written-answer-evaluation.json` v1의 문장과 정답을 모델 응답 전에 작성했다. 모델 응답에 맞춰 정답이나 프롬프트를 수정하지 않았다. 정답은 단일 작성자의 판단이며 독립 평가자 합의는 없다.

| 자료 | 수 | 사전 정답과 일치 |
| --- | ---: | ---: |
| 개발 상황 네 개의 의미를 바꿔 쓴 표현 (상황당 a/b/c/d) | 16 | 16 |
| 무관·지시 변경·무의미·모호 문장 (기대 null) | 4 | 4 |
| 호칭/존대 차이를 제외해야 하는 반말 변형 | 4 | 4 |
| 합계 | 24 | 24 |

`evaluate_written_answers.py`가 실제 로컬 계정으로 별도 로그인한 뒤 앱 `/local-studio/state`와 `/research-api/interview`, `/research-api/interpret`를 호출했다. Auth/저장/공급자 mock이나 어댑터 직접 호출은 사용하지 않았다. 평가 스크립트는 DB를 변경하지 않고 평가용 세션만 로그아웃했다. 브라우저 세션은 유지했다.

- 선택/실제 사용 모델: `nvidia/nemotron-3-ultra-550b-a55b:free`.
- 요청 24개, 해석 완료 24개, 오류 0개, 모델 시도 24회, 모든 응답 비용 보고 0.
- 완료 응답 정답 일치 24/24, 전체 요청 기준 일치 24/24. null도 명시적 정답이며 호출 오류와 구분한다.
- HTTP 왕복 중앙값 약 2.98초, 최댓값 약 14.99초. TTS/iPad 청취 지연이 아니다.
- 자료 SHA256: `a4858a3764a399529fd986413ac259c314517c4367fcdfa779a92619507ee28c`.
- 실행 결과: Git 제외 `runs/research/v2-20261027/authenticated-24/summary.json`, `responses.jsonl`.

**24/24는 이 문장 집합에서의 관찰값이다.** 개발 상황/기존 선택지 의미에 가까운 재서술이 많고 같은 상황의 문장은 독립 표본이 아니다. 실제 보호자의 자유문장·모호한 복합 의도·새로운 상황·다른 무료 모델의 분류 정확도로 일반화할 수 없다. 이 작은 평가로 환각 0, 주입 방어 성공률, 실제 선호 복제를 주장하지 않는다. 다음 검증은 독립 문장 작성자·평가자, 새로운 상황, 오분류 유형과 보류 기준을 포함해야 한다.

화면의 문장별 해석과 fallback은 자동이지만 이 정확도 배치는 명시적으로 실행할 때만 호출한다. 시작/테스트/CI에서 자동으로 공급자를 호출하지 않는다. 무료 모델의 혼잡·계정 한도는 그대로 적용된다.
