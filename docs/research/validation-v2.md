# 대화 맞춤 v2 구현·검증 기록

2026-10-27. 최초 v1의 호칭/말끝 구분 중심 인터뷰를 상황별 표현 전략으로 교체했다. [v1 기록](validation.md)의 5문항 결과를 현재 성능으로 재사용하지 않는다. 실제 환자·임상 음성·체크포인트·배포는 이번 작업에 포함하지 않았다.

## 반영한 동작

- 홈 메뉴의 `대화 맞춤`에서 `말투 인터뷰 / 답변 확인` 인라인 탭을 연다. 브랜드와 홈 메뉴로 돌아갈 수 있으며 이전 `/research`도 유지한다.
- 기존 보호자 저장 API에서 가족 소개·주 호칭·평소 말투·일반 기억을 조회한다. 비어 있으면 가족의 기억으로 안내하고, 조회 실패는 빈 자료로 간주하지 않는다.
- 가족 소개에 다른 호칭 최대 6개와 존댓말/반말/반존대를 추가했다. 가족의 기억 화면에서 수정할 수 있다. 기존 JSON 저장 경로·소유자 검증을 유지하며 새 SQL 마이그레이션은 없다. 과거 데이터의 말투는 임의로 채우지 않는다.
- 인터뷰 후보 12개 중 기본 8문항(8–12개 설정). 각 질문의 네 표현은 감정 반응·질문/제안·설명량이 다르다. 호칭/존댓말 여부를 다시 묻지 않고 저장된 설정을 공통 적용한다. 일부 질문에는 일반 기억의 제목을 반영한다.
- 직접 입력을 선택지보다 먼저 배치했다. 원문 기록·수동 표현 지정·명시적 전송 동의 후 무료 모델 의미 해석을 구분한다. 원문을 기록한 것만으로 학습됐다고 표시하지 않는다.
- 무료 모델 4개 선택, 선택 모델부터 서로 다른 모델 최대 3회(최초+fallback). 모두 실패하면 구조화 오류와 시도 내역을 반환하고 질문·초안·진행을 유지한다. 모델별 0원 가격 검증, 모든 요청의 가격 상한 0, 숨은 provider fallback 차단을 적용한다. 명시적 양수 비용 보고는 즉시 중단한다.
- 자유문장의 의미 해석은 가장 가까운 표현 전략을 분류하는 범위다. 모호하면 분류하지 않고 원문만 남긴다. 실제 환자 답변 생성·인격 복제·의료 판단 기능은 아니다.

## 자동 검증

- 외부 socket 연결을 막은 Python 전체 167개 통과.
- 웹 전체 32파일·98개 테스트, TypeScript/Vite 빌드 통과.
- 아키텍처 생성·check, 생성기 7개 테스트, `git diff --check` 통과.
- 입력 크기는 64KiB로 제한하며 12개×500자 한글을 JSON escape한 replay도 완료하는 회귀 검사를 추가했다.
- 기존 프로필 호환성, 호칭·말투의 실제 SQLite 저장/재조회, 보호자별 원격 저장 계약, 빈 자료/조회 실패 구분, 직접 입력 초안 보존, 화면 이동·키보드 탭을 검사했다. 원격 저장 계약 테스트는 격리된 RPC 대역이며 실제 Supabase DB 왕복 결과가 아니다.
- 무료 모델 테스트는 첫 성공, 실패 후 성공, 세 실패 후 네 번째 미호출, 선택 모델 우선, 비용·가격·지원 기능·출력 검증, 양수 비용 즉시 중단, 잘못된 모델 거부, 오류 비밀 비노출을 포함한다.
- 별도 코드 리뷰에서 발견한 본문 크기 제한 문제를 수정했다. 최종 리뷰에서 추가 수정 요청은 없었다. 도구 일부 연결 실패는 직접 TypeScript 검사·AST 파싱·수동 diff 검토로 보완했다.

## 실제 무료 모델 연결 시험

사용자가 OpenRouter 키를 제공하고 무료 모델 호출을 요청했다. 초기 계정의 무료 모델 데이터 정책 차단은 사용자가 직접 해제했다. 앱은 공급자의 입력 보관·학습 가능성을 전송 동의 옆에 표시한다. 실제 환자 정보나 저장된 가족 소개·기억 전체를 공급자로 보내지 않았다.

Nemotron 3 Ultra `:free`로 직접 작성한 가상 문장 3개를 시험했다. 두 일반 문장은 작성 시 정한 대응 선택지 a/b로 해석했고, 시스템 지시를 바꾸라는 문장은 null(분류 보류)을 반환했다. 세 응답 모두 `usage.cost=0`, 전체 호출 시간은 각각 약 4.37/1.78/1.99초였다. **연결·형식 검증용 세 사례이며 분류 정확도나 주입 공격 방어 성능의 추정치가 아니다.**

최종 fallback 함수도 실제 호출했다. Gemma 4 26B A4B가 공유 공급자 429를 반환한 후 Nemotron 3 Ultra로 넘어가 성공했다. 실제 모델 시도 2회, 비용 보고 0원, 전체 약 2.99초였다. 세 실패의 상한은 네트워크 차단 MockTransport 테스트로 통제해 검증했다. 무료 공급자 오류를 일부러 반복 발생시키는 대량 실험은 하지 않았다.

Gemma 계열의 공유 풀 혼잡과 일부 모델의 공급자 오류를 관찰했다. 특정 harness에서만 허용되는 Inkling은 현재 지원 목록에서 제외했다. 성공한 한 시점의 결과가 이후 가용성이나 다른 문장의 성능을 보장하지 않는다. 기본 모델은 Nemotron 3 Ultra이며 네 후보 모두 매 시도 전 가격을 다시 확인한다.

원시 연결 시험 자료는 Git 제외 `runs/research/v2-20261027/` 아래 보관한다. 키·토큰·공급자 원문 오류는 커밋하지 않는다.

## v2 합성 벤치마크

질문은행은 감정 반응·대화 주도·설명량의 3차원 8가설, 인터뷰 후보 12개·heldout 4개·상황당 4선택지다. 가설, 문장별 style 주석, signal/lapse는 연구자가 정한 가정이다. 모델의 자유문장 해석 정확도를 평가한 벤치마크가 아니다.

최종 재실행 소스는 깨끗한 커밋 `da9f18d75eb162578eebcd57b3b4835c759c5261`(`git_dirty=false`)이다. 네트워크를 차단한 실행은 11.96초였고 공급자 요청은 0건이다. 결과는 Git 제외 `runs/research/v2-20261027/final-benchmark/`에 보관한다.

기본 오프라인 실행은 8프로필×3 seeds×8예산×3전략×2응답자 모형=1,152회, 근거 비교 33×4=132행이다. 프로필 안에서 seed를 평균하고 프로필 단위로 비교한다.

## 화면과 인증 검증의 범위

[화면 증거](../validation/adaptive-care-research/README.md)는 실제 UI·API에 **합성 인증·저장 자료를 제공하는 격리된 QA 서버**를 연결한 것이다. 직접 입력 1개+선택 7개로 8문항 완료, 원문 보존·반영 수 구분, 저장된 기억 제목·반존대 적용, 본문 탭 전환과 예상 답변 우선 표시를 확인했다. 390px에서 문서 폭도 390px였으며 모바일 메뉴와 임시 viewport를 확인 후 복원했다.

실제 8767 서버는 보호자 세션 없이 저장 자료를 읽으려 하면 인증 오류를 보여준다. 실제 계정의 로그인·Supabase DB·모델 호출을 한 번에 잇는 왕복은 이번 검증에 포함하지 않는다. 합성 인증 fixture로 실행한 브라우저 검수를 실제 보호자 권한 검증으로 확대 해석하지 않는다.

## 키·토큰 적용

로컬 `.env`의 `OPENROUTER_KEY`를 `OPENROUTER_API_KEY`, `SUPABASE_TOKEN`을 `SUPABASE_ACCESS_TOKEN`으로 정리했다. 새 관리 토큰은 Git 제외 `.env.deploy.local`에도 동기화했고 파일 권한 0600을 유지했다. 실제 값은 추적하지 않는다.

공식 읽기 전용 API에서 OpenRouter 키 조회 200과 하루 무료 한도 1,000회를 확인했다. 새 Supabase 관리 토큰은 프로젝트 목록 조회 200으로 Favilium 접근을 확인했다. 관리 토큰을 앱 로그인·프로젝트 공개 키로 대체하지 않으며 서버/브라우저에 주입하지 않는다. 연구 서버의 환경 로더는 이번 경로에서 OpenRouter 키만 읽는다.

## 남은 검증

실제 성인/보호자 선호, 독립 heldout 문장에 대한 모델 분류 품질, 강한 LLM/RAG 비교, 실제 음성·iPad 첫 청취음 지연, 섬망 개선 효과는 미검증이다. 실제 환자 적용은 기존 Gate07과 기관·임상 검토가 필요하다. 유료 OpenAI/ElevenLabs 호출·음성 생성·배포·main 병합은 하지 않았다.
