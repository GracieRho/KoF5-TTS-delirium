# 환자 대상 연구 검토

전체 Favilium 서비스의 임상 연구 검토 문서는 [기준 커밋의 원문](https://github.com/GracieRho/KoF5-TTS-delirium/blob/baa1b6bbb30a8c7e53087a7590e38161af91bb50/docs/delirium-familiar-voice/07-pre-patient-trial-safety-ethics-gate.md)에 있습니다. 이 브랜치로 실제 연구를 시작할 때는 보호자 녹음·외부 전송·합성 음성 재생·삭제에 해당하는 절차를 승인된 연구계획과 대조합니다. 연구 시행 승인은 담당 기관에서 확인합니다.
