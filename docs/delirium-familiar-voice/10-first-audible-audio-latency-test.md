# iPad 첫 실제 소리 지연 검증 절차

PRD의 목표는 **발화 종료 → iPad에서 첫 TTS 소리가 나옴**까지 약 1.5~3초다([지연 요구](05-interface-and-runtime.md#52-latency-budget)). 현재 앱의 수치는 발화 **후보 확정 → 네이티브 재생 명령 확인**이다. 후보 확정은 기본 0.9초 무음 판정 뒤이고, iOS [`AVAudioPlayer.play()`](https://developer.apple.com/documentation/avfaudio/avaudioplayer/play%28%29)는 비동기로 시작한다. 따라서 현재 앱 수치로 3초 목표 달성을 주장하지 않는다.

실기기 검사는 내부 시험자의 목소리와 허가된 **합성 시험 음성**만 사용한다. iPad 스피커·고정 볼륨·같은 출력 경로에서 외부 마이크 한 대로 시험자의 마지막 발화와 앱 응답을 같은 시간축의 WAV에 녹음한다. 녹음 파형과 청취를 함께 확인해 마지막 발화 소리의 끝과 응답 첫 **들리는** 소리의 시작을 표시하고 차이를 기록한다. MP3 앞부분의 무음, 에코, 병실 배경 소음이 있으면 먼저 확인한다. 동일 조건에서 10회 반복해 중앙값과 가장 느린 사례를 남기고, `후보 확정→재생 명령 확인` 수치·출력 경로·볼륨·네트워크·공급자 호출 시각을 함께 기록한다. 후보 확정 수치와 외부 소리 수치의 시작점·끝점은 다르므로 직접 빼서 공급자 지연으로 해석하지 않는다.

실제 환자 음성이나 병실 주변 오디오는 [Gate07](07-pre-patient-trial-safety-ethics-gate.md)의 기관·동의·주변 오디오·임상 안전 조건이 닫혀 있는 동안 사용하지 않는다. 내부 시험 녹음은 Git 밖에 두고 시험 뒤 폐기한다. 외부 마이크 검사는 iPad가 **소리를 냈는지**를 확인할 뿐, 환자의 실제 청취·이해를 증명하지 않는다. 실기기·공급자 왕복과 병실 경로 측정 전까지 PRD 지연 목표는 미검증이다.
