# 프로젝트 범위 초안

## 배경

이 프로젝트는 한국어 TTS를 이용해 섬망 환자를 위한 비약물적 중재를 지원하는 것을 목표로 합니다. 구체적인 중재 방식과 임상 적용 범위는 전문가 검토를 거쳐 후속 문서에서 확정합니다.

## 확인된 방향

- 기본 언어: 한국어
- 핵심 기술: 음성 합성(TTS)
- 대상 영역: 섬망 환자의 비약물적 중재 지원
- 장기 배포 방향: 소형 IoT 기기에서의 온디바이스 추론
- 장기 최적화 방향: 모델 경량화 및 디코딩 레이어 프루닝

## 아직 결정하지 않은 항목

- 실제 사용자와 운영 주체
- 음성 안내의 종류, 시점, 빈도 및 상호작용 방식
- 모델 학습 또는 파인튜닝 여부와 데이터 출처
- 목표 음질, 추론 지연 시간, 메모리 및 전력 예산
- 네트워크 연결 여부와 장애 시 동작
- 목표 하드웨어, 운영체제 및 추론 런타임
- 임상 검증, 연구윤리 및 규제 검토 범위

## 초기 성공 기준

상세 요구사항 수립 전에는 다음을 프로젝트 기반의 성공 기준으로 둡니다.

- 요구사항과 기술 결정의 변경 이력을 추적할 수 있을 것
- 민감 데이터와 대용량 모델 산출물이 소스 저장소에서 분리될 것
- 기준 모델과 경량화 모델을 동일 조건에서 비교할 수 있을 것
- 환자 대상 콘텐츠의 검토 상태와 버전을 식별할 수 있을 것
