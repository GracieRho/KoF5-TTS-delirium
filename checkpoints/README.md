# Checkpoints Directory

모델 가중치와 변환 결과를 보관하는 로컬 디렉터리입니다. 체크포인트는 기본적으로 크기와 이력 관리 문제 때문에 Git에서 제외합니다.

현재 [클라우드 중심 MVP](../docs/Delirium_Familiar_Voice_MVP_PRD.md)는 보호자별 모델을 학습하거나 자체 TTS 체크포인트를 배포하지 않습니다. 아래 경로와 선정 기준은 기존·별도 모델 연구에만 적용합니다. Hosted voice ID와 보호자 음성 샘플은 체크포인트가 아닙니다.

- `pretrained/`: 다운로드한 원본 기준 모델
- `finetuned/`: 파인튜닝 결과
- `optimized/pruned/`: 디코딩 레이어 프루닝 결과
- `optimized/quantized/`: 양자화 결과

권장 이름은 `<model>__<purpose>__<date>__<step-or-version>` 형식입니다. 예: `baseline__korean-delirium__20260812__step-10000`.

## Git에 올릴 체크포인트

모든 학습 결과를 올리지 않고, 팀이 재현·비교·배포에 실제로 사용할 **유의미한 체크포인트만 선별**합니다. 다음 조건을 모두 확인합니다.

- 기준 모델 대비 평가 결과와 용도가 문서화되어 있을 것
- 사용한 코드 커밋, 설정, 데이터 버전을 식별할 수 있을 것
- 중간 저장본이 아니라 기준선, 승인된 파인튜닝 결과 또는 배포 후보일 것
- 환자 데이터, 비밀정보 또는 민감한 메타데이터를 포함하지 않을 것
- 저장소 용량 정책을 만족하고 팀 리뷰를 받았을 것

체크포인트 파일은 `.gitignore`에서 기본 제외되므로 선정 후에도 자동으로 추가되지 않습니다. Git에 직접 보관하기로 합의한 파일만 명시적으로 추가하고, 큰 파일은 일반 Git blob 대신 Git LFS 또는 접근통제 가능한 모델 저장소·오브젝트 스토리지를 사용합니다. 외부에 보관하면 위치, 버전과 SHA-256 해시를 실험 기록에 남깁니다.

단순히 loss가 가장 낮다는 이유만으로 선정하지 않습니다. 한국어 명료도, 핵심 문구 보존, 추론 지연, 메모리와 모델 크기를 함께 비교합니다.

직접 추적하기로 승인한 작은 파일은 정확한 경로 하나만 `git add -f checkpoints/<path>`로 추가하고 staged diff와 크기를 다시 확인합니다. `git add -f checkpoints/`처럼 디렉터리 전체를 강제 추가하지 않습니다.
